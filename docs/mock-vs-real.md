# Mock vs real

Home Vibe is a **demo**. This table lists every part that is simulated, so nobody mistakes it for a working shop.

| Area                                                                                     | Status                           | Details                                                                                                                                                                                                                                                                                              |
| ---------------------------------------------------------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Brands                                                                                   | **Mock**                         | All 12 brands are fictional. No real companies, partners or awards are referenced.                                                                                                                                                                                                                   |
| Products & prices                                                                        | **Mock**                         | 65 hand-written products with realistic INR prices and specs. Stock levels are seeded deterministically.                                                                                                                                                                                             |
| Product images                                                                           | **Mock**                         | Generated SVG illustrations served by `/media/art/[kind]/[file]`. Swap them in one place: `getProductImage()` in `packages/data/src/lib/images.ts`.                                                                                                                                                  |
| Reviews                                                                                  | **Mock**                         | ~260 seeded reviews generated from templates, every one labelled “Demo” in the UI. They are deliberately **not** emitted as `aggregateRating` / `review` structured data.                                                                                                                            |
| Testimonials                                                                             | **Mock**                         | Four sample quotes, labelled “Demo” and “not from real customers”.                                                                                                                                                                                                                                   |
| Customer accounts                                                                        | **Mock**                         | Demo logins (`customer@demo.com` / `demo1234`, `admin@demo.com` / `admin1234`). Registered accounts live in the browser where they were created: a salted PBKDF2 hash (never the password) is stored locally for 14 days and checked at sign-in. They cannot sign in from another browser or device. |
| Sessions                                                                                 | Real (demo-grade)                | HMAC-signed, httpOnly cookie verified in `proxy.ts` and again server-side. Uses `AUTH_SECRET`.                                                                                                                                                                                                       |
| Cart, wishlist, compare, recently viewed                                                 | Real (client-side)               | Zustand + `localStorage`.                                                                                                                                                                                                                                                                            |
| Pricing, coupons, shipping, GST                                                          | Real logic, demo data            | `priceCart()` in `packages/data` is the single source of truth. GST rates are indicative.                                                                                                                                                                                                            |
| Checkout & payment                                                                       | **Mock**                         | UPI / card / net banking / COD choice, then a simulated gateway screen with **Simulate success** / **Simulate failure**. No card or bank details are ever collected.                                                                                                                                 |
| Order totals                                                                             | Real                             | `POST /api/orders` recomputes everything from the catalogue and ignores client-sent amounts (covered by an e2e test).                                                                                                                                                                                |
| Orders, profiles, addresses, user reviews                                                | Real persistence, demo retention | `local` adapter (default): browser `localStorage`, purged after 14 days on every app load. `supabase` adapter (optional): tables with `expires_at` + daily `pg_cron` purge.                                                                                                                          |
| Order tracking timeline                                                                  | **Mock**                         | Stages advance automatically by elapsed time (about 15 minutes to “Delivered”).                                                                                                                                                                                                                      |
| Emails / SMS / WhatsApp                                                                  | **Mock**                         | Nothing is sent. The chat button opens WhatsApp only when `NEXT_PUBLIC_WHATSAPP_NUMBER` is set; otherwise it links to the contact page.                                                                                                                                                              |
| Contact form & newsletter                                                                | Real validation, mock delivery   | Zod validation, honeypot and per-IP rate limit on the server; stored locally (or in Supabase). No replies or emails.                                                                                                                                                                                 |
| Delivery estimate (PIN code)                                                             | **Mock**                         | PIN prefixes are mapped to states (India Post circles, approximate); invalid PINs are rejected and transit time grows with distance from the Maharashtra warehouse. Addresses must have a PIN that matches the state.                                                                                |
| Rate limiting                                                                            | Real (single instance)           | In-memory fixed window per IP. Not shared across server instances.                                                                                                                                                                                                                                   |
| Admin analytics                                                                          | **Mock**                         | Monthly sales, seeded customers, admin users and 48 historical orders are seeded.                                                                                                                                                                                                                    |
| Admin “live” orders                                                                      | **Mock**                         | The storefront keeps an in-memory feed of orders placed since it started (`/api/demo-feed/orders`, protected by `DEMO_FEED_TOKEN`). Lost on restart.                                                                                                                                                 |
| Admin edits (prices, stock, order status, coupons, banners, review moderation, settings) | **Mock**                         | Saved in the admin browser's `localStorage` (14-day purge). They do not change the storefront, which reads the static catalogue.                                                                                                                                                                     |
| 3D previews                                                                              | Simplified                       | Procedural low-poly models built from primitives, not real product models.                                                                                                                                                                                                                           |
